# Known Issues — Universal Print Studio

- Local Android build unavailable on Termux (aapt2 is x86_64 only). Verification via GitHub Actions.
- Paper catalog incomplete vs handbook coverage.
- Custom paper manager lacks edit/duplicate/favorite/archive/import/export.
- Editor lacks gestures, undo/redo, layers UI.
- No Android Print Framework integration yet.
- No print queue/history/recovery yet.
- ESC/POS capability flags not per-profile.
- USB discovery lists all USB devices, not just printers.
